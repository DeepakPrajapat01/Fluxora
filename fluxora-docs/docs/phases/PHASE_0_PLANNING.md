# Phase 0 — Planning and Repository Setup

**Goal:** Establish the project boundaries, working agreement, and implementation sequence.

## Tasks
- [ ] Review the PRD, scope, architecture, and domain invariants.
- [ ] Confirm MVP user journeys and roles.
- [ ] Choose initial repository layout.
- [ ] Create Git repository and initial README.
- [ ] Select Java, Spring Boot, Node, package manager, and build-tool versions.
- [ ] Decide Maven vs Gradle and Flyway vs Liquibase.
- [ ] Create initial ADRs for major choices.
- [ ] Create a GitHub issue/backlog from the roadmap.
- [ ] Define what “done” means for each phase.

## Exit criteria
- The first release is small enough to complete.
- The core domain invariants are explicit.
- The initial architecture avoids premature microservices.
- The Phase 1 setup tasks can be executed in order.
